# projects/

One directory per piece, `projects/<slug>/`, holding the whole life of that arrangement —
input, output, and record — instead of scattering them across `source/`, `tabs/`,
`analysis/`, and `logs/`.

**Everything under a project slug is gitignored and stays local.** This repo ships the
toolchain, not arrangements: a piano source is often copyrighted, and a cover is a
derivative work of it, so neither belongs in the public repo. Only this
`projects/README.md` (the layout scaffold) is tracked. Keep your own arrangements local, or
version them in a separate private repo.

| File | Tracked? | What it is |
|---|---|---|
| `source.alphatab` | gitignored | The piano score in AlphaTex (yours, often copyrighted). An acceptable source is *pitched* AlphaTex (`\staff {score}`) — what the header claims the instrument is doesn't matter. |
| `source.json` | gitignored | The machine-readable digest, generated by `piano-extract.mjs`. `compare.mjs` reads this directly and exits 2 if a referenced bar is missing `melodySkeleton`/`harmony`. Regenerate; never hand-edit. |
| `source-map.md` | gitignored | The human-readable bar map — plan the arrangement from this, never from the raw source file. |
| `reference-*.alphatab` | gitignored | Optional non-piano reference recordings/scores (e.g. an existing guitar cover) kept for A/B listening — not a piano source, not gated against. |
| `cover.alphatab` | gitignored | The growing guitar arrangement — one electric-guitar track, fretted notation. No bass track, no backing render. Chunks land here only after `check.mjs` passes. A derivative of the source, so it stays local. |
| `sidecar.json` | gitignored | The span sidecar you write by hand: each tab span mapped to its source span, with a declared mode (`quote` / `recompose` / `free`). Input to `check.mjs --map`, not generated. |
| `sessions.md` | gitignored | Per-song verdict history — every Gate B audition's chunk, sidecar entry, gate result, and the human's call. The record of what was *approved*, not of what was attempted. A defect the toolchain let through doesn't belong here alone — it becomes a fixture in `tools/fixtures/`, enforced by `smoke.mjs`. |
| `scratch/` | gitignored | Throwaway working files for the current chunk. |

Ingest a new source with:
```
node tools/piano-validate.mjs projects/<slug>/source.alphatab
node tools/piano-extract.mjs projects/<slug>/source.alphatab --out projects/<slug>
```

Gate a chunk from inside the project (digest resolves automatically from the co-located
`source.json`):
```
cd projects/<slug> && node ../../tools/check.mjs cover.alphatab --map sidecar.json --bars 1-N
```
